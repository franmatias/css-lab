# Contribuir a CSS Lab

Gracias por ayudar a que aprender CSS sea más claro y práctico.

## Antes de enviar cambios

1. Crea una rama corta a partir de `main`.
2. Usa commits [Conventional Commits](https://www.conventionalcommits.org/), por ejemplo `feat(lab): mostrar coincidencias`.
3. Ejecuta `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test` y, para cambios de interfaz, `pnpm test:e2e`.
4. Comprueba teclado, lector de pantalla, tema claro/oscuro y ancho móvil.
5. Abre un pull request que describa el cambio y cómo se verificó.

Los cambios de contenido deberán incluir IDs estables, soluciones originales y pruebas automatizadas de las soluciones y prerrequisitos. El contenido pedagógico se distribuye bajo CC BY-SA 4.0.
